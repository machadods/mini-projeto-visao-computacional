# Pré-processamento de imagens de peças metálicas

Mini-projeto de visão computacional desenvolvido em Python com a biblioteca OpenCV.

O objetivo é preparar um conjunto de imagens de peças metálicas para uso futuro em um modelo de Machine Learning. O programa fará a leitura das imagens em lote e aplicará diferentes etapas de pré-processamento.

## Preparação do ambiente

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
